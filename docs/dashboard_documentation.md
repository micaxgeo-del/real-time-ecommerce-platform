# Dashboard Documentation

The dashboard provides a business-facing executive view of ecommerce performance.

## Sections

- Executive KPIs
- Revenue trend
- Active users trend
- Category performance
- Traffic source performance
- Conversion funnel
- Device analysis
- Customer segmentation

## Filters

- Date range
- Country
- Device
- Category
- Traffic source

## Run

```bash
streamlit run dashboards/streamlit/app.py
```
